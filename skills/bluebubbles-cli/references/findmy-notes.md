# Find My via BlueBubbles CLI (notes)

Commands:
- `bluebubbles icloud findmy devices list`
- `bluebubbles icloud findmy devices refresh`
- `bluebubbles icloud findmy friends list`
- `bluebubbles icloud findmy friends refresh`

## Reality check

Find My data is scoped to what the Apple ID signed into the BlueBubbles macOS server can see.
This does not grant new access to someones location; they must have shared location with that Apple ID, or the device must belong to that Apple ID.
