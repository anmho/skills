# BlueBubbles Skills

This repository publishes reusable skills for BlueBubbles workflows.

Current skill package:

- `bluebubbles-cli`

Install:

```bash
npx skills add anmho/skills --skill bluebubbles-cli -y
```

This docs site includes:

- Skill usage guidance for `bluebubbles-cli`
- Unified API reference rendered from the SDK OpenAPI spec
