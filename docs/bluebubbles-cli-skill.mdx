# bluebubbles-cli Skill

The `bluebubbles-cli` skill is designed for agents that need to operate BlueBubbles from a terminal.

## What it enforces

- CLI-first execution via `bluebubbles` commands
- API-first behavior for runtime actions
- Local server lifecycle operations only through `bluebubbles server local ...`
- Structured output via `-o table` or `-o json`

## Command families

- Messaging: `chat`, `message`, `message schedule`
- Identity: `handle`, `contact`, `icloud`
- Server and diagnostics: `server`, `ping`, `doctor`, `config`
- Webhooks: `webhook validate`, `webhook serve`
