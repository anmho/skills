# SDK Unification

The Mint API reference in this repository is sourced from the SDK repository directly.

OpenAPI source:

- `https://raw.githubusercontent.com/Jish2/bluebubbles-sdk/main/openapi.yaml`

Local API reference file:

- `docs/openapi.yaml` (generated from the SDK source URL)

This keeps the skill docs and SDK contract aligned while applying a minimal Mint compatibility patch for invalid empty `responses` objects.

## Why this setup

- Single source of truth for endpoints and schemas
- Skill guidance can reference the same API contract agents use
- Mint automatically renders endpoint pages from the OpenAPI URL

## Local docs workflow

```bash
npm install
npm run docs:sync-openapi
npm run docs:dev
```

Validate before pushing:

```bash
npm run docs:validate
```
